\### Présentation

\### Fonctionnalités principales



\- création et gestion des comptes utilisateurs ;

\- gestion des candidats ;

\## 📊 3. Analyse des offres d'emploi avec Python



\### Présentation



Ce projet est consacré à l'analyse d'un ensemble d'offres d'emploi à l'aide de Python.



L'objectif est de charger, explorer, analyser et représenter les données afin d'en extraire des informations compréhensibles.



\### Objectifs



\- mettre en pratique Python pour l'analyse de données ;

\- manipuler des données avec Pandas ;

\- réaliser des statistiques descriptives ;

\- créer des visualisations ;

\- interpréter les résultats obtenus ;

\- structurer un projet d'analyse de données.



\### Analyses réalisées



\- chargement d'un fichier CSV ;

\- exploration des données ;

\- statistiques descriptives ;

\- analyse des salaires ;

\- analyse des offres par ville ;

\- comparaison des postes ;

\- calcul du salaire moyen ;

\- visualisation graphique des résultats.



\### Technologies utilisées



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Jupyter Notebook

\- CSV

\- Git

\- GitHub



\### Visualisations réalisées



Le projet contient notamment :



\- une visualisation des salaires proposés par poste ;

\- une visualisation du nombre d'offres d'emploi par ville ;

\- une visualisation du salaire moyen par ville ;

\- une représentation de la distribution des salaires.



\### Dépôt GitHub



👉 https://github.com/hamdaahmedsaid1-wq/analyse-offres-emploi-python
